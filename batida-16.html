Para quem quer um desafio: a música passa de 16 para 32 passos.

Bumbo, caixa e chimbal: toque para ligar e desligar. Baixo e melodia: cada toque troca a nota. Para uma nota durar mais, segure nela e arraste para o lado. Toque na parte esticada para encurtar. Toque no nome de uma linha (Baixo, Melodia...) para silenciar. Segure o dedo (ou o botão esquerdo do mouse) num quadrado para abrir o menu. O botão direito do mouse apaga o quadrado na hora.
